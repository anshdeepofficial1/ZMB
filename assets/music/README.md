# 🎵 Music Folder

Yahan 2-3 **dark ambient / horror drone** tracks daalo (`.mp3`).

## Kahan se (100% free, no attribution):

1. [pixabay.com/music](https://pixabay.com/music/) → search: `dark ambient`, `horror drone`, `suspense tension`
2. Koi bhi track kholo → **Download** (free, license-safe, Instagram tak usable)
3. File ko is folder mein daalo: `assets/music/track1.mp3` etc.

## Kaise use hota hai:

- Script har episode ke liye random track chunta hai
- Volume automatic low rakhha jata hai (`config.json` → `music_volume: 0.12`)
- Music na ho to video sirf voice ke saath banti hai (channel rukta nahi)

⚠️ Instagram ka apna library music API se nahi lag sakta (licensing) — isliye yahi tareeka hai.
